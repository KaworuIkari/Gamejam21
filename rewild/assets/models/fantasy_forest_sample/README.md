# 奇幻森林 · 首批模块样品

按已确认需求制作：约 18 米巨树、环树平台与模块化树屋、石拱门。以约 1.8 米人物为尺度，包含简单室内、静态碰撞和组装示例，无家具。

## 预览与文件

- `previews/assembly.png`：整体 Blender 渲染。
- `previews/treehouse_detail.png`：树屋近景 Blender 渲染。
- `fantasy_forest_sample.blend`：可编辑源文件，贴图已打包。打开时展示组装效果，原始模块隐藏。
- `assets/*.glb`：26 个模块，贴图嵌入，可单独导入。
- `assets/*.tscn`：为每个模块添加基础静态碰撞的 Godot 包装场景。
- `sample.tscn`：完整组装示例。
- `manifest.json`：各模块三角形统计与碰撞类型。
- `assembly.json`：所有实例在 Godot 坐标系中的位置与旋转。
- `build_assets.py`：Blender 生成脚本，原素材路径在脚本开头。
- `validation.json`：GLB 结构与资源引用检查结果。

## 在 Godot 中使用

用 Godot 4.x 导入本目录的 `project.godot`，等待素材导入，然后运行项目。示例使用兼容性渲染器。尚未在 Godot 实际运行验证；当前验证覆盖 Blender 导出、渲染以及 GLB 结构与场景文件引用。

鼠标左键拖拽旋转，滚轮缩放；数字 1/2/3 切换总览、树屋、拱门视角。Tab 切换步行，WASD 移动，鼠标观察，空格跳跃，Esc 释放鼠标，R 重置位置。示例步行控制器含简单台阶处理，正式游戏应使用项目自己的角色控制器。

迁移到其他工程：将 `assets` 文件夹放在目标工程根目录，保持 `res://assets/` 路径；如需更改目录，同时更新 `.tscn` 引用。单独使用 GLB 不受此限制，但 GLB 自身不包含此包的 Godot 碰撞设置。

## 模块尺寸和拼装

单位：米。Godot 为 Y 向上，Blender 为 Z 向上。模块的轴心和变换已用于示例装配，精确位置见 `assembly.json`。

| 模块 | 尺寸或规则 |
|---|---|
| GiantTree_18m | 保留原素材分枝与叶片，改造到约 18 米并增加根部 |
| Platform_Wedge30 | 30°扇形，共 12 块成环；内半径 1.5 米，外半径约 5.92 米 |
| Railing_Wedge30 | 配套平台外缘；入口和房屋占用处留空 |
| Floor_2x2 | 2×2 米，4 块组成 4×4 米树屋地板 |
| Wall_Solid_2m / Wall_Door_2m / Wall_Window_2m | 2 米墙宽，2.8 米墙高；独立实墙、门洞墙、窗洞墙 |
| Door_Frame / Window_Frame | 独立门框与窗框；门为约 1.2 米宽、2.2 米高的开放门洞，无活动门扇 |
| Gable_4m / Roof_Gabled_4x4 | 山墙与双坡屋顶独立；屋顶包含出檐 |
| Stair_Step | 1.6 米宽，单步高 0.2 米，水平步距 0.3 米 |
| Stair_Stringers / Stair_Rails | 匹配示例 18 级楼梯的完整支撑与扶手 |
| Support_Brace | 平台下方斜撑 |
| Arch_Pier | 拱门左右共用立柱部件 |
| Arch_Voussoir_01…09 | 9 个拱石，共同形成半圆拱；按既定位置拼装 |
| Arch_Moss_Cap | 柱顶苔藓装饰，无碰撞 |

树屋地板位于离地 3.6 米；拱门内净宽约 2.5 米，中心净高约 3.9 米。石拱门拱石以拱圆心为轴心，编号部件不需要额外旋转即可组装。

## 来源、风格与当前边界

巨树是用户提供的 `TwistedTree_3.gltf` 的衍生改造，复用其树皮、法线、树叶与原始分枝拓扑，调整比例、上部弯曲和树冠净空，并新增根部。它不是从零设计的新树种。树屋、平台、楼梯和拱门几何是本次新建。

建筑木材复用 `Bark_NormalTree.png` 并做材质调色；石块复用 `Rocks_Diffuse.png`；屋顶使用多种青绿色粗糙材质。屋顶尚未单独绘制手绘贴图。以上做法用于首批风格确认；原素材授权仍沿用素材自身条件。

巨树碰撞为简化主干圆柱，不覆盖全部树枝和树根。其他主要建筑模块使用静态三角网格碰撞，门窗开口保留。此碰撞适合静态环境，不适合作为可推动的刚体。模型尚未制作专用 LOD、烘焙光照 UV、风动或破坏动画；大规模铺设前需要进一步优化网格、材质与碰撞。

预览是 Blender 渲染，Godot 的灯光与色彩管理不同，最终观感以引擎实测为准。
