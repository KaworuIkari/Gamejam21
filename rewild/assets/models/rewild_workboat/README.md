# Extracted harbour workboat

Workboat.tscn: the six original boat parts combined into one placeable object, with their existing materials and static collisions. No shed or support cradle. Origin is at hull bottom (original local Y minus 1 metre).

Workboat_With_Cradle.tscn: the same boat on the original support cradle. The Cradle child can be removed independently. Origin is at the cradle base.

These Godot scenes reference the original island_harbor/assets part scenes; retain those files. Workboat.glb is a portable visual-only export with embedded materials/textures. It does not include Godot collision or boating gameplay.

Original harbour scene and models remain unchanged. preview.png shows the extracted boat.
