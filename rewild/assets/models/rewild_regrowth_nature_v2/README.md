# Rewild — approved nature style, v2

20 placeable props, each with a barren base, separate greenery overlay, and combined Restorable scene. Includes fitted overlays for the harbour, crashed plane, and Desert Robotics Laboratory.

Open sample.tscn in the Godot editor for the prop gallery. Place any *_Restorable.tscn into your level. Preview Green on its Greenery child toggles editor foliage; during play the existing GrowthMap controls growth. Threshold 0.6, growth animation 0.8 seconds, stagger up to 1.2 seconds. Each plant patch samples the ground beneath itself. Base geometry and collision remain fixed.

meadow_with_regrowth.tscn inherits meadow_hand and adds all three landmark overlays under the matching landmark roots. The existing older Overgrowth nodes are hidden and disabled only in this preview to avoid doubled foliage. The original meadow scene and previous packs are unchanged. Use this inherited scene to try the overlays in the existing level.

The approved log, wall and bench are preserved. Other timber and stone props reuse the same nature-pack textures. Greenery uses original fern, clover and flower meshes with trailing vines. Barren stone retains the lichen baked into the original rock texture.
