# 字体来源与许可（均为 SIL OFL 1.1，可商用、可内嵌）

- `NotoSansSC-Regular-subset.otf`：Noto Sans CJK SC Regular（思源黑体），已裁剪到 GB2312 全部汉字 + 拉丁 + 日文假名 + 常用符号/箭头，约 3.6MB。
  生僻字不在字库内时 Godot 会回落到系统字体；需要完整字库可换成官方完整版 OTF。
- `LXGWWenKai-Regular.ttf`：霞鹜文楷 Regular，由 lxgw-wenkai-webfont@1.7.0 的分片合并而来（14026 字形）。
- 许可文本见同目录 `OFL-LXGWWenKai.txt`、`NOTICE-NotoSansCJK.txt`。
