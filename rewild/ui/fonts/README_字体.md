# UI 字体与许可文件

## 当前使用

`ui/theme/light/light_theme.tres` 与 `ui/theme/glass/glass_theme.tres` 的默认字体均为 `SarasaUiCL-Regular.ttf`（Sarasa UI），按钮、标题和名牌等控件使用主题内的 `SarasaUiCL-SemiBold.ttf`。实际字体覆盖以主题资源和控件设置为准；主菜单艺术标题另使用图片。

`UIType` 的 12 字号步长是保留下来的排版规则，不代表当前默认使用像素字体。

## 其他保留字体

`fusion-pixel-12px.ttf`、`ChillBitmap7x.ttf`、`NotoSansSC-Regular-subset.otf`、`LXGWWenKai-Regular.ttf` 是可供旧主题或其他界面使用的资源，不等同于当前默认字体。是否可删除须检查实际引用，不能仅凭本说明判断。

## 本目录的许可说明

- `OFL.txt` 文件头对应 Fusion Pixel。
- `OFL-LXGWWenKai.txt` 对应霞鹜文楷。
- `NOTICE-NotoSansCJK.txt` 为 Noto Sans CJK 相关说明。

现有许可文件不应统一描述为覆盖本目录所有字体。新增、替换或分发字体时，应保留对应字体自身的来源与许可文本。
