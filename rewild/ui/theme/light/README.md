# 明亮 UI 主题

本目录负责当前菜单及自定义对话图层的明亮主题。

- `light_theme.tres`：按钮、面板、标签、滑块等主题资源，主要使用 StyleBoxFlat。
- `light_ui.gd`：为动态控件应用主题，并添加局部模糊背景。
- `light_backdrop.gdshader`：独立的背景模糊着色器。
- 本目录的 PNG：主题使用的局部控件纹理。
- `pause_light_style.gd`：保留的独立面板样式脚本，当前暂停场景没有挂载它；不要将它当成现用暂停菜单的唯一入口。

默认正文使用 `ui/fonts/SarasaUiCL-Regular.ttf`，按钮及部分标题使用 SemiBold。菜单场景显式引用本主题，确认弹窗和动态存档卡片通过 LightUI 应用主题。

本主题不依赖玻璃目录来实现自身的背景模糊，但项目全局主题和对话中的部分素材仍使用 `ui/theme/glass/`。因此不能以明亮主题已启用为理由删除玻璃目录。

主题纹理保留各自的导入身份，不把另一主题的 `.import` 或 `.uid` 当成通用文件复制覆盖。调整视觉参数时检查主题资源、实际场景及 LightUI 的共同设置。
